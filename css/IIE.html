Inline CSS:

This is used in an HTML page using style attributes.

Internal CSS:

It means add a style tag and place the HTML page's style within it.

External CSS:

Mostly used way to apply CSS. It means to create a .css file and place all your styles inside that .css file.

Three ways to add CSS to HTML

  1. Inline CSS
  2. Internal CSS
  3. External CSS
