Inline style > Id selector > Class or Attribute Selector > Element Selector > universal Selector

Important is most important than inline style.

CSS Specificity.

To Calculate speciflicity: assign a value to each part of the selector:

  • Universal selector: 0
  • Element selector and pseudo-elements: 1
  • Class selector, attribute selectors and pseudo-classes: 10
  • Id selectors: 100
  • Inline style: 1000

Then, add up the values of all the parts in the selector.
